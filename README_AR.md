# نظام إدارة مكتب الحزمي — Alhazmi

## مكونات المشروع
- موقع عام للدورات والتسجيل الإلكتروني وجدول المحاضرات وطرق الدفع.
- لوحة مدير محمية بتسجيل دخول.
- إدارة الطلاب وحالاتهم.
- إضافة الدورات وتفعيلها أو إيقافها.
- تسجيل الدفعات.
- إدارة جدول المحاضرات.
- تسجيل النتائج وأرقام الشهادات ونشرها والتحقق منها.

## النشر المجاني على Render

### 1) تجهيز GitHub
1. أنشئ مستودعاً جديداً باسم `alhazmi`.
2. ارفع جميع ملفات هذا المشروع إلى المستودع، مع الحفاظ على المجلدات `templates` و`static`.
3. لا ترفع ملف قاعدة بيانات حقيقياً أو كلمات مرور أو ملف `.env`.

### 2) إنشاء خدمة Render
1. سجّل الدخول إلى Render واربط حساب GitHub.
2. اختر New ثم Blueprint أو Web Service واربط مستودع `alhazmi`.
3. إذا اخترت Blueprint فسيقرأ Render إعدادات `render.yaml` تلقائياً.
4. اختر الخطة Free إن طُلب منك ذلك.
5. عيّن متغيرات البيئة التالية في إعدادات الخدمة:
   - `ADMIN_USERNAME`: اسم مستخدم إداري تختاره.
   - `ADMIN_PASSWORD`: كلمة مرور طويلة وفريدة لا تشاركها مع أحد.
   - `DATABASE_URL`: رابط اتصال PostgreSQL من مزود قاعدة بيانات تختاره.
   - `SECRET_KEY`: ينشئه Render تلقائياً عبر `generateValue` في Blueprint.
6. ابدأ النشر وانتظر نجاح Build وDeploy.
7. افتح رابط الخدمة، ثم أضف `/admin/login` للدخول إلى لوحة الإدارة.

## تنبيه أساسي بشأن حفظ البيانات
خطة Render المجانية توقف خدمة الويب بعد فترة من عدم النشاط، كما أن نظام الملفات المحلي مؤقت؛ لذلك قاعدة SQLite المحلية ليست مناسبة لحفظ بيانات الطلاب على الإنترنت. لا تستخدم الموقع لتسجيل بيانات حقيقية قبل ضبط `DATABASE_URL` على قاعدة PostgreSQL دائمة ومراجعة النسخ الاحتياطي والخصوصية.

قاعدة Render PostgreSQL المجانية تنتهي بعد 30 يوماً ولا توفر نسخاً احتياطية؛ لذلك لم نربطها تلقائياً في ملف النشر. يمكن استخدام قاعدة خارجية، لكن يجب مراجعة شروطها وحدودها وخطة النسخ الاحتياطي قبل وضع بيانات الطلاب فيها. إن لم تتوفر قاعدة بيانات دائمة موثوقة، اجعل النشر للمعاينة فقط ولا تدخل بيانات حقيقية.

## حدود النسخة الحالية
- لا توجد بيانات طلاب أو دورات فعلية مضافة مسبقاً؛ أضف الدورات والأسعار من لوحة الإدارة بعد إعداد قاعدة البيانات.
- صفحة التسجيل تحفظ الطلب في قاعدة البيانات؛ لا تعتمد على مجرد ظهور رسالة النجاح قبل التأكد من اتصال قاعدة البيانات.
- حذف الطالب يحذف أيضاً دفعاته ونتائجه المرتبطة به.
- لا تنشر نتائج الطلاب أو أرقام هواتفهم دون موافقتهم.
- قبل الاستخدام التشغيلي، أضف سياسة خصوصية، وحدد من يحق له الاطلاع على بيانات الطلاب، واختبر النسخ الاحتياطي والاستعادة، واطلب مراجعة أمنية مستقلة.

## تشغيل محلي للاختبار
1. ثبّت Python 3.11 أو أحدث.
2. أنشئ بيئة افتراضية وثبّت المتطلبات: `pip install -r requirements.txt`.
3. عيّن `SECRET_KEY` و`ADMIN_USERNAME` و`ADMIN_PASSWORD`.
4. للاختبار المحلي فقط، عيّن `COOKIE_SECURE=0`.
5. شغّل: `python app.py`.
6. افتح `http://127.0.0.1:5000`، ولوحة الإدارة `http://127.0.0.1:5000/admin/login`.
